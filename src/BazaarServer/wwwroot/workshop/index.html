🤖 让 AI 替你写 Mod（复制即用提示词）

本仓库已内置专属工业级技能 bazaar-mod-creator（位于 docs/skills/bazaar-mod-creator/SKILL.md 与 .agents/skills/bazaar-mod-creator/SKILL.md），支持 Antigravity / Cursor / Claude Code 自动遵循 10 道防 Bug 铁闸。

模板 1：一句话生成原创主题卡牌与奇遇包 
请激活 bazaar-mod-creator 技能，为《The Bazaar》自建服创建一个新 Mod（id: frost-alchemy，中文名：霜火炼金工坊）：
1. 基于原版白名单克隆 2 件物品（1 件 Small 冰冻武器、1 件 Medium 灼烧提灯）与 1 个连携技能；
2. 制作 1 个 2 步合法奇遇事件链（严格使用 TTriggerOnCardSelected 与标准动作，禁止虚构 effects 字段）；
3. 必须跑完 python tools/mod_sdk_cli.py validate mods/frost-alchemy --strict --offline-sim 直到 10/10 铁闸全绿且 50 场真实战斗 0 异常后再交付！
模板 2：给原版热门卡做平衡性原位补丁 
请激活 bazaar-mod-creator 技能，创建一个原位平衡补丁 Mod（id: classic-rebalance）：
1. 用 python tools/mod_sdk_cli.py clone-card --search 查出原版 Kukri 等 3 张武器 GUID，使用 --mode patch 写入 patches/vanilla_patches.json；
2. 适度下调青铜/白银冷却 0.5 秒并追加 Tool 标签；
3. 运行 validate 与 sim-test 跑 50 场真实战斗确认胜率健康、0 异常后打包成 .bazaarmod.zip。

⚡ 三种创作路径与命令行 SDK 速查

路径适合人群优点
Web 零代码工坊所有玩家 / 策划浏览器直开、自动锁白名单、秒转 ms、拖图转 PNG
AI Skill 一句话生成效率创作者自动查 3,368 原版库、自动避坑、自动跑 50 场战斗自检
CLI + JSON / C# SDK硬核开发者可进 Git 协作、CI 自动化验证、支持自定义规则钩子

常用 CLI 指令（tools/mod_sdk_cli.py）

# 1. 初始化标准 Mod 骨架
python tools/mod_sdk_cli.py new my-forge --name "星港锻炉" --author "你的名字"

# 2. 检索 3,368 原版白名单卡并一键克隆 / 生成原位补丁
python tools/mod_sdk_cli.py clone-card --search "Kukri" --type Item --size Small
python tools/mod_sdk_cli.py clone-card "Kukri" --mod my-forge --as storm_kukri --mode clone
python tools/mod_sdk_cli.py clone-card "Kukri" --mod my-forge --mode patch

# 3. 跑满 10 道防 Bug 铁闸 + 50 场真实战斗体检
python tools/mod_sdk_cli.py validate mods/my-forge --strict --offline-sim
python tools/mod_sdk_cli.py sim-test mods/my-forge --matches 50

# 4. 打包分享 & 安全检疫解包
python tools/mod_sdk_cli.py pack mods/my-forge -o dist/mods/my-forge.bazaarmod.zip
python tools/mod_sdk_cli.py unpack dist/mods/my-forge.bazaarmod.zip --into mods/
